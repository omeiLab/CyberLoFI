# Starry Music Box — 星光音樂盒 🎵✨

一個基於 Web Audio API 開發的互動式音樂盒與環境音效播放器。專為放鬆、專注與睡眠設計，結合了晶瑩剔透的音樂盒音色、夢幻殘響與多種白噪音情境。

---

## 🌟 專案特色

- **純 Web Audio API 聲學合成**：完全不依賴外部音樂檔案，透過正弦波、鋸齒波與泛音疊加，呈現極致透明的星光音樂盒音色。
- **立體聲殘響系統 (Convolver Reverb)**：模擬廣闊空間感，讓每個敲擊音符帶有柔和且深邃的尾音。
- **精選動態情境 (Preset Scenarios)**：收錄多款精心編排的自動循環旋律，搭配相應的環境音效（雨聲、篝火、海浪、風聲）。
- **視覺化波紋效果 (Canvas Visualizer)**：隨著旋律與音符互動，動態繪製流暢的聲波能量曲線。
- **鍵盤與觸控支援**：支援電腦鍵盤按鍵與觸控螢幕點擊，隨時敲擊屬於你自己的音符。

---

## 🛠️ 技術架構與檔案說明

- `index.html`：整體 UI 結構與琴鍵配置。
- `style.css`：暗色系夢幻視覺樣式與動態高亮。
- `audio.js`：Web Audio 音聲合成引擎、殘響濾鏡與音符觸發邏輯。
- `ambient.js`：白噪音（雨聲、風聲等）演算法生成與音量控制。
- `data.js`：音符頻率表、環境音設定與情境旋律數據。
- `visualizer.js`：Canvas 畫布聲波繪製與能量回饋機制。
- `app.js`：事件綁定、情境切換與使用者偏好儲存 (`localStorage`)。
- `lofi.md`：音色合成原理與情境旋律細節說明。

## 🚀 快速開始

1. 下載或 Clone 本專案所有檔案。
2. 直接在瀏覽器中開啟 `index.html`（建議使用 Chrome、Edge 或 Safari 等支援 Web Audio API 的現代瀏覽器）。
3. **點擊頁面任意處**（解鎖瀏覽器音訊限制），即可點擊琴鍵或選擇情境開始體驗！
