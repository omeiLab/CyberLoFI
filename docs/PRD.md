
# PRD：Lo-Fi 氛圍聲音小站 (Chill Soundboard)

## 1. 專案概述 (Overview)
 * 專案名稱：Lo-Fi Chill Station / 賽博放鬆微型音樂盒
 * 目標：提供一個無廣告、開啟即用的網頁放鬆空間。使用者可以透過點擊按鈕或敲擊鍵盤，疊加環境音效與琴鍵旋律，打造專屬的專注/放鬆氛圍。
 * 部署方式：GitHub Pages（純靜態 HTML/CSS/JS）。
## 2. 核心功能規格 (Core Features)
### 🎵 A. 環境白噪音混合器 (Ambient Sound Mixer)
 * 包含音效：
   * 🌧️ 深夜雨聲 (Rain)
   * 🪵 柴火營火聲 (Fireplace)
   * ☕ 咖啡廳背景音 (Cafe)
   * 🌊 海浪聲 (Waves)
 * 互動方式：
   * 每個音效都有獨立的 開關 Toggle 與 音量滑桿 (Volume Slider)。
   * 使用者可以同時開啟多個音效進行聲音疊加（例如：雨聲 + 柴火聲）。
   * 採用 HTML5 Web Audio / 合成或輕量化 免費音效檔。
### 🎹 B. 互動式琴鍵與音效墊 (Interactive Synth Pad)
 * 鍵盤映射：
   * 支援電腦鍵盤按鍵（如 A, S, D, F, G, H, J）。
   * 按下鍵盤或點擊畫面上的按鈕時，會發出柔和的 Lo-Fi 暖色調鋼琴/合成音階（C, D, E, F, G, A, B）。
 * 視覺反饋：
   * 按下的瞬間，按鈕會有發光/縮放的呼吸燈效果。
### 🎨 C. 視覺與氛圍設計 (Visual & Vibe)
 * 主題風格：Dark Mode 深色模式，採用 Soft Neon (柔和霓虹) 或 Cyber-Lofi 色系（深紫、粉藍、柔黃）。
 * 動態視覺：
   * 畫面中央加入一個簡單的音效波紋或粒子動畫，發出聲音時會有動態響應。
 * 響應式設計 (Responsive)：
   * 支援電腦與手機螢幕瀏覽。
## 3. 技術架構與介面設計 (Tech & Architecture)
| 項目 | 技術方案 |
|---|---|
| 網頁結構 | 單一 index.html 檔案（內含 HTML, CSS, JS），方便管理與部署 |
| UI 樣式 | CSS Grid / Flexbox，搭柔和霓虹陰影 (box-shadow) |
| 音訊處理 | Web Audio API（自動生成柔和音階音效，免載入大檔案）+ 輕量環境音 |
| 資料儲存 | LocalStorage（自動記憶使用者上次設定的音量與偏好） |
## 4. 使用者流程 (User Flow)

```
[開啟網頁] 
   │
   ├───> 點擊「白噪音開關」 ───> 播放雨聲/柴火聲 (可自由調整音量大小)
   │
   ├───> 按下鍵盤 A-G 鍵   ───> 觸發柔和合成音階 + 畫面霓虹發光粒子效果
   │
   └───> 關閉網頁/下次開啟 ───> 自動載入上一次調整好的偏好設定
```
