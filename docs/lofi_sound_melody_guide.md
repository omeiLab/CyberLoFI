# 🎶 星光音樂盒 — 音色合成與旋律設計指南 (Lofi & Ambient Guide)

本文件詳細記錄了《星光音樂盒》在 Web Audio API 下的聲學合成設計，以及各個精選情境（Scenarios）的旋律架構理念。

---

## 🎹 1. 音色合成設計 (Sound Design)

音樂盒音色（Music Box Synth）主要透過四個不同屬性的震盪器（Oscillators）與動態 Envelope 疊加而成：

### 1.1 音色組成
1. **Bell Attack (清脆敲擊聲)**：
   - 使用 4 倍高頻正弦波，並在 0.004 秒內極速起音（Ramp Up），模擬金屬小鎚敲擊音板時的清脆顆粒感。
2. **Fundamental (主音底色)**：
   - 採用自訂的週期波形（Periodic Wave）與少量三角波（Triangle Wave），維持音符圓潤且飽滿的基音。
3. **High Harmonics (晶瑩泛音)**：
   - 加上 2 倍高八度正弦波，賦予音樂盒如同水晶般的透亮感。
4. **Sawtooth Edge (金屬質感)**：
   - 透過低通濾鏡（Lowpass Filter at 900Hz）截斷高頻後的極少量鋸齒波，補充金屬齒輪微弱的摩擦質感。

### 1.2 空間殘響 (Spatial Reverb)
- **Convolver Impulse Response**：
  - 生成 3.5 秒長度的立體聲脈衝響應，讓敲擊後的尾音自然擴散於空間中，創造深夜星空下的空靈氛圍。

## 🌌 2. 情境旋律編排 (Preset Scenarios)

每個情境均結合了特定白噪音與精心挑選的音符時間差（Delay），形塑不同的情境故事：

### 🏡 Cozy Corner (雨夜窗邊)
- **環境音**：雨聲 (`rain`)
- **調性/氛圍**：溫暖、微甜、柔順。
- **設計理念**：以 E5 與 G5 輕快交錯，營造窗外雨滴與室內燈光交織的安心感。

### 🪵 Midnight Cabin (深夜木屋)
- **環境音**：篝火 (`fire`) + 風聲 (`wind`)
- **調性/氛圍**：深邃、寂靜、略帶孤獨感。
- **設計理念**：拉長音符間隔，結合 A4、E5 與 A5 的低語，如夜空中偶爾閃爍的遠方星光。

### 📚 Midnight Library (深夜圖書館)
- **環境音**：雨聲 (`rain`)
- **調性/氛圍**：沉穩、專注、微光。
- **設計理念**：使用雙音同時敲擊（如 `F4 + C5`），形塑如同翻開書頁時空氣中漂浮的塵埃感。

### 🌅 Sunset Balcony (夕陽陽台)
- **環境音**：海浪 (`waves`) + 風聲 (`wind`)
- **調性/氛圍**：浪漫、浪漫、帶有些許懷舊感。
- **設計理念**：起伏較大的階梯式音符，象徵晚霞暮光隨海風緩緩流動。

### 🌊 Ocean Breeze (月光潮汐)
- **環境音**：海浪 (`waves`)
- **調性/氛圍**：舒緩、寧靜、連綿不絕。
- **設計理念**：旋律如潮汐般推升與退去，帶來極佳的放鬆與助眠效果。
